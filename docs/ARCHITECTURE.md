# 实现与恢复语义

1. 预检流式读取，记录字节偏移、物理行号和消息哈希，丢弃原始消息对象；worker 按需读取单条轨迹，原始长轨迹不全部常驻内存。
2. filelock 对输出目录加锁，防止两个程序同时操作同一输出。空锁文件不含打标数据，操作系统在进程结束时释放锁。
3. 每个 worker 的 LLM client 和 Pipeline 独立；单条内部按 A/B/C 顺序执行。
4. SQLite WAL + synchronous FULL 保存尝试与最终结果；共享连接由 RLock 保护，worker 自行提交，不依赖主线程消费完成事件。
5. 从断点/嵌入评分/已有注释副本恢复，校验消息哈希、配置指纹、引用与汇总。模型、提示词、截断或分段改变会使旧结果失效。
6. 正常结束或安全中断后逐文件合成完整结果，只写入评分叶字段。保留空行；临时文件 fsync、哈希读回、os.replace，再重读核对消息哈希和评分。
7. 输出前再次校验原始整文件 SHA-256；运行期间外部编辑输入则阻止覆盖。原地写回在全部 active worker 结束后进行，避免输入偏移变化。
8. 完成最终数据、统计与 HTML 后关闭 SQLite。检查临时目录父路径、名称及 .owned 标记后，只递归删除本次 run_id 目录；空父目录仅 rmdir。

失败、限额、中断或写回/报告失败保留状态。新程序运行重新给失败条目 max_attempts 预算，复用成功阶段。原地 .bak 不自动覆盖。
